# คอร์ส Go — บทเรียนที่ทำแบบฝึกหัดได้จริง

สรุปจากสไลด์คอร์ส **PEA DevPool — Enterprise Go Engineering with AI Integration**
เรียบเรียงใหม่เป็นเว็บบทเรียนภาษาไทย 27 บท ที่มี predict-the-output, quiz
ที่ให้ feedback ทันที และภารกิจให้ลงมือเขียนโค้ดทุกบท

**ตัวอย่างโค้ดทุกอันถูกรันจริงบน Go 1.26 ก่อนเผยแพร่** — ระหว่างทำเจอจุดที่สไลด์ผิด 11 จุด
บันทึกไว้ใน [learning record 0002](learning-records/0002-course-slides-have-errors.md)

## เว็บไซต์

เป็น static site ล้วน ไม่มี build step ไม่มี dependency ไม่มี tracking
เปิด `index.html` ก็ใช้ได้ทั้งหมด (ยกเว้นหน้า `docs.html` — ดูหัวข้อ "เปิดในเครื่อง")

| เส้นทาง | คืออะไร |
|---|---|
| `index.html` | สารบัญทุกบท + แถบความคืบหน้า |
| `day-N/lessons/NNNN-slug.html` | บทเรียน (เลขบทต่อเนื่องข้ามวัน) |
| `day-N/reference/cheatsheet.html` | สรุปของวันนั้น พิมพ์ลงกระดาษได้ |
| `docs.html` | ตัวอ่านเอกสาร `.md` ทั้งหมดในรีโป |
| `assets/` | CSS + JS ที่ทุกหน้าใช้ร่วมกัน |

## Deploy บน Vercel

รีโปนี้พร้อม deploy อยู่แล้ว ไม่ต้องตั้งค่าอะไรเพิ่ม

1. Vercel → **Add New… → Project** → เลือกรีโปนี้
2. Framework Preset: **Other** (Vercel เดาให้เองอยู่แล้ว)
3. Build Command / Output Directory: **เว้นว่างทั้งคู่**
4. กด Deploy

จากนั้นทุกครั้งที่ push ขึ้น `main` Vercel จะ deploy ใหม่อัตโนมัติ
ส่วน branch อื่นจะได้ Preview URL ของตัวเอง

`vercel.json` ในรีโปกำหนดไว้แค่สองเรื่อง: cache header และการเสิร์ฟไฟล์ `.md`
เป็น `text/plain` เพื่อให้เปิดอ่านในเบราว์เซอร์ได้แทนที่จะถูกดาวน์โหลด

## เปิดในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย บทเรียนทุกบททำงานครบ

ยกเว้น `docs.html` ที่ต้องอ่านไฟล์ `.md` ผ่าน `fetch()` ซึ่งเบราว์เซอร์บล็อกบน
โปรโตคอล `file://` — ถ้าจะดูหน้านั้นในเครื่อง ให้รันเซิร์ฟเวอร์สักตัวก่อน

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## ความคืบหน้าของแต่ละคน

ติ๊ก "ทำบทนี้เสร็จแล้ว" ท้ายบทเรียน หรือติ๊กในสารบัญก็ได้ — เก็บลง `localStorage`
ของเบราว์เซอร์ตัวเอง **ไม่มีการส่งข้อมูลไปไหน ไม่มีบัญชี ไม่มี server**
แปลว่าใครเปิดก็มีความคืบหน้าของตัวเอง แต่ก็ไม่ sync ข้ามเครื่อง

คะแนน quiz ในแต่ละบทไม่ถูกบันทึก ตั้งใจให้ตอบใหม่ได้ทุกครั้งที่กลับมาทบทวน

## เพิ่มวันใหม่

1. สร้าง `day-N/lessons/` และ `day-N/reference/`
2. เขียนบทเรียนต่อจากเลขล่าสุด (`NNNN-slug.html`) — คัดลอกโครงจากบทที่มีอยู่
   ทุกบทต้องมี quiz 4 ข้อ, predict อย่างน้อย 1, ภารกิจ 1, แหล่งอ้างอิง, scorebar, nav
3. เพิ่ม `day-N/reference/cheatsheet.html`
4. เพิ่ม `<section class="day">` ในสารบัญ `index.html` พร้อม `<li class="lesson" data-id="NNNN">`
5. แก้เลขรวมในแถบความคืบหน้าของ `index.html`
6. ต่อ nav ของบทสุดท้ายวันก่อนหน้าให้ชี้มาบทแรกของวันใหม่

ปุ่ม "ทำบทนี้เสร็จแล้ว" ไม่ต้องเขียนเพิ่ม — `assets/quiz.js` อ่านเลขบทจากชื่อไฟล์แล้วแทรกให้เอง

รายละเอียดมาตรฐานของบทเรียนอยู่ใน [NOTES.md](NOTES.md)

## เพิ่มเอกสาร .md ใหม่

เขียนไฟล์ `.md` ตามปกติ แล้วเพิ่มหนึ่งบรรทัดในอาร์เรย์ `DOCS` ใน `docs.html`
ตัวอ่าน markdown อยู่ที่ `assets/md.js` — รองรับ heading / ตาราง / code / list /
blockquote เท่าที่เอกสารชุดนี้ใช้ ถ้าต้องใช้ syntax ที่ยังไม่รองรับ ให้เพิ่มในไฟล์นั้น
อย่าเขียน HTML ปนลงไฟล์ `.md`

## ที่มาและขอบเขต

  เพราะเป็นสื่อการสอนของ PEA DevPool
- ทำไว้ใช้เรียนกันเองในกลุ่มผู้เข้าอบรม ไม่ใช่สื่อทางการของคอร์ส
- ถ้าเจอจุดที่ผิด เปิด issue ได้เลย — ทั้งเว็บนี้เกิดจากการจับผิดสไลด์อยู่แล้ว
