# 0017 — เขียนบท Rails Day 1 ใหม่ทั้งหมดสำหรับมือใหม่มาก ๆ (บท 90–105)

**วันที่:** 3 พฤศจิกายน 2026
**ที่มา:** ผู้เรียนอ่านชุดแรก (record 0016) แล้วงงตั้งแต่บทแรก — สั่งว่า
"ใช้ slide เป็น ref เฉย ๆ ว่าฉันเรียนเรื่องอะไร แล้วปรับเป็นสำหรับมือใหม่มาก ๆ อธิบายแบบเปรียบเทียบทุกจุด"

---

## ทำไมชุดแรกใช้ไม่ได้

คำถามที่ผู้เรียนถามหลังอ่านชุดแรก บอกปัญหาได้ตรงที่สุด:

| คำถาม | ปัญหาของบทชุดแรก |
|---|---|
| "posts คืออะไร เห็นหลายครั้งตั้งแต่บทแรก" | ใช้ `Post` `posts` `Post.where(...)` ตั้งแต่บท 90 โดยไม่มีใครบอกว่าเป็นแค่ "บทความในบล็อก" |
| "ใน Go ประกาศ struct, func แล้ว ใน Rails Post มาเฉย ๆ ได้ไง" | ไม่มีบทไหนเล่าว่า `class Post < ApplicationRecord` ได้คอลัมน์มาจากตาราง `posts` |
| "gem เหมือน package ของ Go ไหม" | เทียบกับ Go แบบผ่าน ๆ ไม่ได้เทียบทีละบรรทัด |

และบทชุดแรก**เต็มไปด้วยกล่อง "สไลด์ผิดตรงนี้"** — มีประโยชน์กับคนที่ถือสไลด์อยู่
แต่กับมือใหม่มันคือเสียงรบกวน ทำให้ไม่รู้ว่าอะไรคือเนื้อหาหลัก

## การตัดสินใจ

### 1 · ชื่อไฟล์ เลขบท และ `data-id` เหมือนเดิม — เปลี่ยนแค่ชื่อบทและเนื้อหา

เลขบทคือคีย์ของ `localStorage` · ถ้าเปลี่ยนชื่อไฟล์ ใครที่ติ๊ก "เสร็จแล้ว" ไว้จะหาย ·
ชื่อบทใหม่อยู่ใน `nav.js` (`RAILS`) · `index.html` · และ `<h1>` ของแต่ละบท

### 2 · ภาพเปรียบเทียบกลางชุดเดียวทั้งวัน: ร้านอาหาร

ทุกบทใช้ภาพชุดเดียวกัน เพื่อให้บทหลังต่อยอดบทก่อนได้ ไม่ต้องเรียนภาพใหม่ทุกบท:

| Rails | ร้านอาหาร |
|---|---|
| browser · request · response | ลูกค้า · ใบสั่ง · จานอาหาร |
| server (Puma) | เปิดร้าน · ประตูร้าน |
| routes | พนักงานต้อนรับ (รายการในมือ) |
| controller · action · params | หัวหน้าเชฟของแผนก · เมนู · รายละเอียดในใบสั่ง |
| model · database · table | ห้องเก็บวัตถุดิบ + คนดูแลสต็อก · ตู้เก็บแฟ้ม · ลิ้นชัก |
| view · layout · helper | คนจัดจาน · จานรองมาตรฐาน · เครื่องมือจัดจาน |
| middleware | ด่านหน้าครัว |
| gem · Gemfile · Gemfile.lock | อุปกรณ์สำเร็จรูป · รายการซื้อของ · ใบเสร็จ |
| Convention over Configuration | ร้านแฟรนไชส์ — ทุกสาขาวางของที่เดิม |
| console · debugger | ครัวทดลองหลังร้าน · กดหยุดเวลาในครัว |

Go ในภาพนี้คือ "สร้างร้านเองจากห้องเปล่า" · Rails คือ "ได้ร้านแฟรนไชส์มาทั้งร้าน" ·
ทุก analogy ยังต้องมีท่อน "ที่ไม่เหมือนกัน:" ตามกฎเดิม

### 3 · ก่อนมี Rails จำลองบทความด้วย Hash

บท 91–97 เป็น Ruby ล้วน · แทนที่จะโชว์ `Post.where(...)` ที่ยังรันไม่ได้
ใช้ `{ title: "ต้มยำกุ้ง", published: true }` แทนบทความ แล้วเขียนกำกับทุกครั้งว่า "(ยังไม่มี Rails)" ·
บท 95 ค่อยสร้าง `class Post` เอง แล้วสะพานไปบอกว่า Post ของ Rails ต่างกันตรงไหน

### 4 · เรื่องสไลด์ผิด ย้ายไปไว้ท้ายบท

ทุกบทมีหัวข้อสุดท้ายก่อน nav ชื่อ **"ถ้าเปิดสไลด์ดูประกอบ"** เป็นตารางสั้น ๆ ·
เนื้อหาหลักไม่พูดถึงสไลด์เลย · รายการเต็มของจุดที่สไลด์ผิดยังอยู่ใน record 0016

### 5 · ผลรันฝั่ง Rails ใช้พอร์ต 3000 ทั้งหมด

ชุดแรกใช้พอร์ต 4090–4105 แล้วเขียน note บอกให้ผู้เรียนนึกเป็น 3000 · มือใหม่สะดุดตรงนี้ ·
รอบนี้ทุก agent ต่อคิวใช้พอร์ต 3000 ผ่านล็อก (`mkdir` lock) เพื่อให้ผลที่โชว์ตรงกับที่ผู้เรียนจะเห็นจริง

## pipeline ที่ใช้ (workflow 51 agent)

1. **เขียน** — 16 บทพร้อมกัน แต่ละบทรันทุกผลจริงใน sandbox ของตัวเอง
2. **อ่านแบบมือใหม่** — agent ที่สวมบทคนไม่รู้ Ruby อ่านแล้วจดทุกจุดที่งง → คนเขียนแก้
3. **ตรวจและแก้** — auditor รันซ้ำทุกบล็อก · เช็คเฉลย quiz ด้วยผลรันจริง
4. **อ่านทั้งคอร์สตามลำดับ** — agent เดียวอ่าน 90 → 105 หาจุดที่บทอ้างกันผิด และภาพเปรียบเทียบที่ชนกัน
5. **cheat sheet** — เขียนจากบทใหม่ทั้ง 16 บท แล้วตรวจอีกรอบ

หลังจากนั้นรันซ้ำเองแบบสุ่ม: บล็อก `.rb` ทุกอันในบท 90–97 (64 อันตรงกับที่บทโชว์ ·
ที่เหลือเป็นบล็อกที่ต้องรันใน Rails หรือมีเลข address ที่ต่างทุกรอบ) · ภารกิจบท 93 · `bin/rails routes` ของบท 101

## ที่เจอระหว่างทาง (เผื่อรอบหน้า)

- **บรรทัดคอมเมนต์ชื่อไฟล์ทำให้เลขบรรทัดใน error เลื่อน** — โค้ดที่ขึ้นต้นด้วย `# first.rb`
  ถ้าผู้เรียนพิมพ์ตามทั้งบล็อก error จะชี้บรรทัดถัดลงไปหนึ่งบรรทัด · auditor เจอและแก้ใน 5 บท (90 · 91 · 94 · 95 · 99) ·
  **รันโค้ด "ตามที่โชว์" รวมคอมเมนต์บรรทัดแรก ไม่ใช่รันฉบับที่ไม่มีคอมเมนต์**
- **ภาพเปรียบเทียบชนกันข้ามบท** — เช่นบท 94 เรียก Hash ว่า "ตู้มีลิ้นชัก" แต่ภาพกลางใช้ตู้ = database ·
  บท 98 เรียก Puma ว่า "คนเปิดประตูรับลูกค้า" ปนกับพนักงานต้อนรับ (routes) ·
  agent ที่เขียนบทเดียวมองไม่เห็นเรื่องนี้ ต้องมีรอบอ่านทั้งคอร์ส
- **ลิงก์ "ดูต่อในบท N" ชี้ผิดบท** — เจอหลายจุดในบท 93 · 98 · 102 · 105 (เช่นบอกว่า Rails.logger อยู่บท 104 แต่บท 104 ไม่มี) ·
  แก้ในรอบอ่านทั้งคอร์สทั้งหมด
- **agent เปิดแท็บเบราว์เซอร์ค้างไว้จนเต็ม** — ต้องปิดก่อน sweep รอบสุดท้าย
