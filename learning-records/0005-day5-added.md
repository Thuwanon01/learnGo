# Day 5 เข้าระบบ — วันที่ผู้เรียนได้เครื่องมือตรวจงานตัวเอง

เพิ่มบทเรียน 14–18 จากสไลด์ Day 5 (Pre) 50 หน้า
ตามขั้นตอนใน [[NOTES.md]] หัวข้อ "เวลาเพิ่มวันใหม่"

**ทำไมวันนี้เปลี่ยนสถานะของผู้เรียน:** ห้าวันแรกผู้เรียนต้องเชื่อว่าโค้ดที่เขียนถูก
หรือรอให้ผมบอก **Day 5 คือวันที่เขาตรวจเองได้** — และนั่นเปลี่ยนวิธีที่ควรสอนต่อจากนี้:
ภารกิจในบทถัดไปควรลงท้ายด้วย "เขียนเทสพิสูจน์" แทน "ลองรันดู"

**ข้อสังเกตเชิงการสอน:** สไลด์วันนี้เป็น **API surface ล้วน ๆ** (รายการ method
รายการ flag รายการ assert) ซึ่งเป็นเนื้อหาที่จำไม่ได้จากการอ่าน
บทเรียนจึงเปลี่ยนน้ำหนัก:

- **ลด**การไล่รายการ method → ยกไป cheat sheet ทั้งหมด
- **เพิ่ม**การเทียบคู่ที่คนสับสน (Error/Fatal · assert/require ·
  Cleanup/defer · internal/external) เพราะรู้ว่า *เลือกอันไหนเมื่อไหร่*
  มีค่ากว่ารู้ว่ามีอะไรบ้าง
- predict-the-output ของวันนี้เน้น **"ตัวเลขที่เห็นเชื่อได้ไหม"** —
  ทั้ง `(cached)`, coverage 100%, และเวลาของ `t.Parallel()`
  ล้วนเป็นตัวเลขที่หลอกคนอ่านได้

**จุดที่รันแล้วเจอ ซึ่งสไลด์ไม่ได้บอก** (ยืนยันบน Go 1.26.5 + testify v1.11.1):

| เรื่อง | สิ่งที่พบ |
|---|---|
| `t.Cleanup` ตอน fail | รันครบและเป็น **LIFO** เหมือน `defer` — ผูกกับ*เทส* ไม่ใช่*ฟังก์ชัน* จึงใช้ใน helper ได้ |
| `t.Helper()` | ไม่ใส่ → error ชี้บรรทัด 43 (ในตัว helper) · ใส่ → ชี้บรรทัด 59 (จุดที่เรียก) |
| build tag ไม่มีบรรทัดว่าง | **ยังทำงานได้** แต่ `gofmt -l` ฟ้อง — ต่างจากที่สไลด์บอกว่า "ต้อง" · ที่พังจริงคือวางไว้*ใต้* `package` → `misplaced compiler directive` |
| testify suite | เรียงเทส **ตามตัวอักษร** ไม่ใช่ตามลำดับในไฟล์ |
| `assert.Equal` กับ custom type | `string("A") ≠ Grade("A")` — ต่อยอดจากบทเรียน 09 ได้พอดี |
| float + constant folding | `assert.Equal(t, 0.3, 0.1+0.2)` **ผ่าน** (compiler คำนวณให้ตั้งแต่ build) แต่ผ่านตัวแปรแล้ว **ไม่ผ่าน** — เรื่องเดียวกับ `int(3.9)` ในบทเรียน 02 |
| ลืม `.On()` ใน mock | panic พร้อมข้อความที่บอกค่า argument จริงที่ได้รับ เอาไปวางใน `.On()` ได้เลย |
| TDD: Red สองแบบ | `[build failed]` ไม่ใช่ Red ที่ใช้ได้ — เทสยังไม่เคยรัน · ต้องเขียนโครงเปล่าให้คอมไพล์ผ่านก่อน |

**Implications:**
- เรื่อง "float + constant folding" กับ "custom type ใน `assert.Equal`"
  เชื่อมกลับไปบทเรียน 02 และ 09 ได้ตรง ๆ — **ใส่ cross-link ไว้แล้ว**
  เป็นหลักฐานว่าโครงบทเรียนที่เรียงมาถูกทาง
- สไลด์ Day 5 เป็นไฟล์ **"(Pre)"** — น่าจะเป็นฉบับก่อนเรียน
  ถ้าได้ฉบับเต็มมาทีหลัง ต้องเทียบว่ามีหัวข้อเพิ่มไหม
- ยังไม่มี **Generics** ทั้งที่อยู่ใน outline ของ Day 4
  (ดู [[0002-course-slides-have-errors]]) — ผ่านมาสองวันแล้วยังไม่โผล่
