## ที่เจอระหว่างทาง (เผื่อรอบหน้า)

- **IRB ย่อผลของบรรทัดที่เป็นการกำหนดค่า** — `post = Post.new` บนจอจริงแสดง `=>` / `#<Post:0x…` / `...`
  ไม่ใช่บรรทัดเดียวยาว ๆ · writer บท 106 เขียนแบบบรรทัดเดียว auditor จับได้แล้วแทนด้วยผลจริง
- **`db:prepare` บน DB ใหม่ = load schema + seed ให้แล้ว** · สั่ง `db:seed` ซ้ำข้อมูลเบิ้ลเป็น `[6, 12, 14]` ·
  บท 107 สอน `db:migrate:reset` แล้วค่อย `db:seed` แยก
- **`bin/rails runner` เปิด query cache แต่ console ไม่เปิด** — N+1 ใน runner จะเห็นบรรทัด `CACHE`
  ส่วนใน console ไม่เห็น · ผลในบท 114 ฝั่ง console ไม่มี CACHE ฝั่ง server มี CACHE ถูกทั้งคู่
- **`status: :unprocessable_entity` ขึ้นคำเตือน deprecated ใน Rack 3.2** (ได้ 422 เหมือนเดิม) ·
  บท 111 เคยใช้ชื่อเก่าในโค้ดของบทเอง → เปลี่ยนเป็น `:unprocessable_content` เหลือชื่อเก่าเฉพาะตรงที่ยกโค้ดสไลด์
- **`parameterize` เก็บขีดล่าง `_` ไว้ด้วย** (`"Noodle_Soup 2"` → `"noodle_soup-2"`) ·
  บท 112 / 119 เขียนว่าเก็บแค่ตัวอังกฤษ ตัวเลข ขีด → แก้แล้ว
- **`runner` กับข้อความไทยตอน LANG ว่าง** ระเบิด `Cannot transliterate strings with ASCII-8BIT` ·
  ตั้ง `LANG=en_US.UTF-8` ก่อนรัน (ปัญหาเครื่องที่ตรวจ ไม่ใช่ของผู้เรียน)
- **สถานะของผู้เรียนสะสมข้ามบท** — คอลัมน์ / constraint / model ที่เพิ่มในบท 110–116 ค้างอยู่ในเครื่องผู้เรียน
  แต่ผลในบทรันบนข้อมูลฐาน · บท 112 · 115 · 116 · 117 มีกล่องบอกว่าต่างได้ตรงไหนและ reset ยังไง
