# จุดตั้งต้น: เห็นเนื้อหา Day 3 ครบแล้ว แต่ยังไม่มีหลักฐานว่าใช้เป็น

ผู้เรียนระบุตัวเองว่า "พึ่งเริ่มเรียน Golang" และได้รับการอธิบายเนื้อหา Day 3
ครบทั้ง 107 หน้าไปแล้วหนึ่งรอบในรูปแบบข้อความ (function ขั้นสูง, array/slice/map/
struct, pointer & memory, defer, method & receiver)

**ทำไมถึงสำคัญ:** นี่คือ *coverage* ไม่ใช่ *learning* — ยังไม่มีหลักฐานว่าใช้
concept ไหนได้ถูกต้อง บทเรียน 0001–0003 จึงออกแบบเป็น **retrieval practice**
(predict-the-output + quiz ปิดตำรา) แทนที่จะเป็นการแนะนำแนวคิดใหม่ เป้าหมายคือ
เปลี่ยน fluency ที่ได้จากการอ่าน ให้กลายเป็น storage strength

**Implications:** อย่าเพิ่งสอนเนื้อหาใหม่จนกว่าจะเห็นผล quiz จาก 3 บทแรก
ถ้าทำได้เกิน 80% แสดงว่าประเมินต่ำไป ให้ข้ามไป struct embedding / workshop
ท้ายสไลด์ได้เลย ถ้าต่ำกว่านั้นให้ทำ lesson เสริมเฉพาะจุดที่พลาด
