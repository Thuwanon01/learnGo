# เปิดให้เพื่อนใช้ — จาก workspace ส่วนตัวเป็นเว็บสาธารณะ

ผู้เรียนขอเอาทั้งชุดขึ้น GitHub + Vercel ให้เพื่อนร่วมคอร์สใช้ด้วย
โดยต้อง **interact ได้เหมือนที่ตัวเองใช้อยู่**

## สิ่งที่ไม่ต้องทำอะไรเลย

การตัดสินใจตั้งแต่วันแรกว่าเป็น HTML + CSS + JS ล้วน ไม่มี framework
ไม่มี build step ทำให้ deploy คือการ push แล้วชี้ Vercel มาที่รีโป จบ
**quiz / predict / ปุ่มเฉลย / แถบคะแนน ทำงานฝั่งเบราว์เซอร์ทั้งหมดอยู่แล้ว**
เพื่อนที่เปิดเว็บจึงได้ประสบการณ์เดียวกันโดยไม่ต้องแก้อะไร

บทเรียนที่ได้: **ความ "น่าเบื่อ" ทางเทคนิคคือสิ่งที่ทำให้ขยายได้ทีหลัง**
ถ้าตอนนั้นเลือก framework ไว้ ตอนนี้จะต้องมาแก้ build config แทนที่จะเพิ่ม feature

## สิ่งที่ต้องออกแบบเพิ่มจริง ๆ

| เรื่อง | ตอนใช้คนเดียว | ตอนเปิดให้เพื่อน |
|---|---|---|
| ความคืบหน้า | ติ๊กในหน้าแรกพอ | เพิ่มปุ่มติ๊กท้ายบทเรียนด้วย — คนอ่านจบอยู่ที่ท้ายบท ไม่ใช่หน้าแรก |
| เอกสาร `.md` | เปิดใน editor | บนเว็บ เบราว์เซอร์จะ **ดาวน์โหลด** ไฟล์ `.md` แทนที่จะเปิดอ่าน |
| สไลด์ต้นฉบับ | เก็บไว้ในโฟลเดอร์ | เป็นสื่อของผู้สอน **ไม่ push ขึ้น repo สาธารณะ** |
| ข้อความปิดท้าย | "คุยกับผมได้" (คุยกับ AI) | เพื่อนอ่านแล้วงง — เปลี่ยนเป็นชวนเปิด issue |

## การตัดสินใจที่ควรจำ

**ปุ่ม "ทำบทนี้เสร็จแล้ว" ไม่แตะไฟล์บทเรียนเลยสักไฟล์**
`quiz.js` ถูกโหลดอยู่ในทั้ง 27 บทอยู่แล้ว จึงให้มันอ่านเลขบทจาก
**ชื่อไฟล์** (`0019-generics.html` → `0019`) แล้วแทรกการ์ดเองเหนือ `<nav>`
→ เพิ่มบทที่ 28 ในอนาคตก็ได้ปุ่มนี้ฟรีโดยไม่ต้องจำว่าต้องใส่

ทางเลือกที่ไม่เอา: แก้ HTML ทั้ง 27 ไฟล์เพื่อใส่ markup — งานเท่ากันในวันนี้
แต่กลายเป็นขั้นตอนที่ต้องจำไปตลอดทุกบทที่เพิ่มทีหลัง

**เขียน markdown renderer เองแทนการแปลง `.md` เป็น `.html`**
เอกสาร 10 ไฟล์ (glossary, resources, learning records) ยังต้องแก้บ่อย
ถ้าแปลงเป็น HTML จะมีสองแหล่งความจริงทันที
จึงทำ `assets/md.js` (~200 บรรทัด ไม่มี dependency) + `docs.html?f=<path>`
รองรับเฉพาะ syntax ที่เอกสารชุดนี้ใช้จริง — heading, ตาราง GFM, code, list,
blockquote, hr และ inline ปกติ

**จุดที่ต้องระวังเป็นพิเศษกับภาษาไทย:** เอกสารตัดบรรทัดเองที่ ~80 คอลัมน์
ถ้า join บรรทัดด้วยช่องว่างตามปกติของ markdown จะได้ช่องว่างโผล่กลางประโยคไทย
→ renderer เช็คตัวอักษรสองฝั่งของรอยต่อ **ถ้าเป็นไทยทั้งคู่ให้ต่อกันเลย**

## ราคาที่ต้องจ่าย

`docs.html` ใช้ `fetch()` ซึ่งเบราว์เซอร์บล็อกบน `file://` (CORS)
→ **หน้านี้หน้าเดียวที่เปิดจากไฟล์ในเครื่องตรง ๆ ไม่ได้** บทเรียนทั้ง 27 บท
กับหน้าแรกยังเปิดได้ปกติเหมือนเดิม · หน้าจับกรณีนี้แล้วขึ้นวิธีแก้
(`python3 -m http.server`) พร้อมลิงก์ไปไฟล์ดิบ ไม่ปล่อยให้จอว่างเปล่า

รับได้ เพราะการใช้งานจริงหลังจากนี้คือเปิดผ่าน URL ที่ deploy แล้ว

## ที่ยังไม่ทำ (จงใจ)

- **ไม่มี backend / บัญชีผู้ใช้** — ความคืบหน้าอยู่ใน localStorage ของแต่ละเครื่อง
  เพื่อนแต่ละคนแยกกันเองอัตโนมัติ แลกกับการไม่ sync ข้ามเครื่อง
  ถ้าวันหนึ่งอยากได้ leaderboard หรือดูว่าใครติดบทไหน ค่อยคุยเรื่อง backend
- **ไม่เก็บคะแนน quiz** — ตั้งใจให้ตอบใหม่ได้ทุกครั้งที่กลับมาทบทวน
  ถ้าเก็บไว้จะกลายเป็นการสอบ ซึ่งขัดกับที่ออกแบบมาให้เดาผิดได้ฟรี
