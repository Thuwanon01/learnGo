2 · ติดตั้ง

VS Code

ลง extension ชื่อ Go (id: golang.go, publisher: Go Team at Google)

mise — จัดการเวอร์ชัน Go

# ติดตั้ง mise (Linux / macOS / WSL)
curl https://mise.run | sh
mise --version

# เปิดใช้งานใน shell
echo 'eval "$(~/.local/bin/mise activate zsh)"' >> ~/.zshrc   # zsh
echo 'eval "$(~/.local/bin/mise activate bash)"' >> ~/.bashrc  # bash

# ตั้ง Go เป็น global
mise use --global go@1.26
go version

# หรือกำหนดเฉพาะโปรเจกต์ (สร้างไฟล์ mise.toml)
mise use go@1.26

# รันโดยไม่ต้องติดตั้งถาวร
mise exec go@1.26 -- go version
# mise.toml
[tools]
go = "1.26.4"

ประโยชน์: คนละโปรเจกต์ใช้ Go คนละเวอร์ชันได้ และเพื่อนร่วมทีมได้เวอร์ชันเดียวกันอัตโนมัติเพราะ mise.toml อยู่ใน repo

3 · Go modules

go-to-hero/ ├── go.mod ← module path + Go version + dependencies ├── go.sum ← checksum กันคนสลับของ └── main.go
mkdir go-to-hero && cd go-to-hero

go mod init go-to-hero                              # ชื่อสั้น
go mod init gitlab.com/username/go-to-hero          # ชื่อเต็ม (ถ้าจะเผยแพร่)

go mod tidy      # เพิ่มของที่ใช้ + ลบของที่ไม่ใช้ ← รันบ่อย ๆ

Module = ชุดของ package ที่ release/version/distribute ไปด้วยกัน

4 · โครงสร้างโปรแกรม

package main          // ชื่อ main = executable / ชื่ออื่น = library

import (
    "fmt"
    "math/rand"       // เรียกใช้ด้วย rand.Intn() ← ชิ้นสุดท้ายของ path
)

func init() { ... }   // รันก่อน main เสมอ · มีหลายตัวได้ · เรียกเองไม่ได้

func main() { ... }   // จุดเริ่มต้น · ไม่รับ param ไม่คืนค่า · มีตัวเดียว

ลำดับการทำงาน

1. import package ทั้งหมด (รัน init ของ package นั้น ๆ ก่อน) 2. ประกาศตัวแปรระดับ package 3. init() ← ตามลำดับที่เขียน 4. main()

ใช้ init() เท่าที่จำเป็น — มันรันเงียบ ๆ โดยไม่มีใครเรียก ทำให้ไล่โค้ดยาก ถ้าเขียนเป็นฟังก์ชันธรรมดาแล้วเรียกจาก main ได้ ให้ทำแบบนั้น

5 · เครื่องมือ

คำสั่งทำอะไร
go run .compile ชั่วคราว → รัน → ลบทิ้ง (ตอนพัฒนา)
go buildcompile เป็น binary เก็บไว้ (ตอน deploy)
go fmt ./...จัดรูปแบบโค้ดให้เป็นมาตรฐานเดียวกันทั้งโลก
go vet ./...หาโค้ดที่ compile ผ่านแต่น่าจะผิด
go mod tidyจัดระเบียบ dependency
go build -gcflags="-m"ดูว่าตัวแปรไหน escape ไป heap
go run . go build main.go source + dependencies ↓ ↓ load package Go compiler ↓ ↓ compile → binary ชั่วคราว Linker ↓ ↓ รัน → ลบทิ้ง binary จริง เก็บบนดิสก์

Cross-compilation — จุดขายใหญ่ของ Go

GOOS=linux GOARCH=amd64 go build -o bin/app
GOOSGOARCH
windows · darwin (macOS) · linux · freebsd · android · ios · js (WebAssembly) amd64 (64-bit x86) · 386 (32-bit x86) · arm64 · arm · riscv64 · wasm

Type conversion — T(v)

i := 42
f := float64(i)
u := uint(f)

var x, y int = 3, 4
var dist float64 = math.Sqrt(float64(x*x + y*y))

Go ไม่แปลง type ให้อัตโนมัติ — int + float64 = compile error

Type inference — default type ของค่าคงที่

n := 42      // int      (ไม่ใช่ int64)
f := 3.142   // float64  (ไม่ใช่ float32)
s := "hi"    // string
b := true    // bool

9 · กับดัก Day 1

เขียนคิดว่าเกิดจริง
import "os" แล้วไม่ใช้แค่ warning 💥 compile error "os" imported and not used
ประกาศตัวแปรแล้วไม่ใช้ไม่เป็นไร 💥 declared and not used
count := 0 นอกฟังก์ชันได้เหมือนในฟังก์ชัน 💥 non-declaration statement outside function body
i + f (int + float64)Go แปลงให้ 💥 mismatched types → ต้อง float64(i) + f
a / b เมื่อทั้งคู่เป็น intได้ทศนิยม 5/2 = 2 ตัดเศษทิ้ง → แปลงเป็น float64 ก่อนหาร
int(f) เมื่อ f = 3.9ปัดเป็น 4 3 — ตัดทิ้ง ไม่ปัด
uint8(big) เมื่อ big = 300error หรือ 255 44 — ล้นแล้ววนกลับเงียบ ๆ
int(3.9) ใส่ค่าคงที่ตรง ๆเหมือนผ่านตัวแปร 💥 compile error — constant Go ตรวจได้ตั้งแต่ compile time
len("สวัสดี")ได้ 6 18 — นับ bytes → ใช้ len([]rune(s))
