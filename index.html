REST API & Gin — วันแรกที่มีคนอื่นยิงเข้ามา

  • 33 · REST: ทุกอย่างคือ resource 14 นาที บทแรกที่ไม่มีคอมไพเลอร์คอยด่า เพราะคนเรียกอยู่คนละเครื่อง · URI vs path vs path parameter · stateless แปลว่าอะไรจริง ๆ · PUT กับ PATCH ที่ทำให้ข้อมูลหายโดยไม่มี error
  • 34 · Status code: ตัวเลขที่บอกว่าใครผิด 13 นาที 4xx = client ต้องแก้ · 5xx = เราต้องแก้ — เส้นแบ่งเดียวที่ต้องจำ · 401 vs 403 · 400 vs 409 · ทำไม ตอบ 200 พร้อม {"error":…} ถึงแพงที่สุด
  • 35 · query · body · header: ส่งเข้าไปทางไหน 13 นาที หนึ่ง request มีสี่ช่อง ส่งผิดช่องแล้ว server อ่านไม่เจอเงียบ ๆ · คำถามสามข้อที่ตัดสินให้จบ · ยิง token ทาง query แล้วเปิด log ให้ดูว่ามันไปโผล่ตรงไหน
  • 36 · กฎตั้งชื่อ 7 ข้อ · versioning · idempotency 16 นาที URL คือ signature ที่ compiler ไม่ช่วยเช็ค · จับผิดสไลด์หน้า 35 ที่ติด ✅/❌ กลับด้าน · DELETE ซ้ำครั้งที่สองควรตอบ 404 หรือ 204 · เพิ่ม field ใหม่นับเป็น breaking change ไหม
  • 37 · net/http: เซิร์ฟเวอร์ตัวแรก ไม่ใช้ framework 18 นาที ผ่านมา 36 บทยังไม่เคยเปิดพอร์ตสักครั้ง — บทนี้เปิดด้วย stdlib ล้วน · ServeMux + method pattern (Go 1.22+) · r.PathValue · ResponseWriter เขียนได้ครั้งเดียว — และ log บรรทัดเดียวที่บอกว่าคุณพลาดตรงไหน
  • 38 · Gin: router ที่อ่านออก และ Context ที่ทำงานแทน 16 นาที รีแฟกเตอร์โค้ดบท 37 เป็น Gin ทีละบรรทัด แล้ววาง response จริงเทียบกัน · ช่องที่ 405 กลายเป็น 404 เงียบ ๆ · และความจริงเรื่อง “/users/:id ชนกับ /users/me แล้ว Gin panic” ที่หลายบทความเขียนผิด
  • 39 · binding · validation · middleware · CORS 18 นาที binding:"required" ที่ปฏิเสธ 0 ที่ผู้ใช้ตั้งใจส่ง · ShouldBindJSON vs BindJSON กับ warning ที่ตามมา · c.Next() ที่รันสองรอบ · cors.Default() ไม่อนุญาต Authorization
  • 40 · httptest: ทดสอบ handler โดยไม่ต้องเปิดเซิร์ฟเวอร์ 16 นาที เลิก go run . แล้วกด F5 — ServeHTTP เป็นแค่ฟังก์ชันธรรมดา · NewRecorder + NewRequest · assert.JSONEq vs assert.Equal · ไม่มีในสไลด์ แต่ค้าง backlog มาตั้งแต่ Day 5
  • 41 · Swagger: เอกสารที่ไม่มีวันเก่ากว่าโค้ด 18 นาที annotation → swag init → docs/ → Swagger UI · ทำให้มันพังให้ดูก่อน แล้วค่อยแก้ — เวอร์ชัน CLI ไม่ตรงกับ library · ลืม blank import · ลืม *any
  • 42 · Wongnok: ออกแบบ API spec จากโจทย์จริง 20 นาที ไม่มีของใหม่สักชิ้น มีแค่โจทย์ธุรกิจสี่บรรทัด ให้แปลงเป็น spec เอง · แล้ววิจารณ์ spec ของผู้สอนด้วยกฎ 7 ข้อ — รวมถึงสี่บรรทัดที่ขัดกฎอย่างมีเหตุผล
