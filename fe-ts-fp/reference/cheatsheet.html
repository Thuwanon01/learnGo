2 · type พื้นฐาน + วิธีเขียน

กลุ่มเขียนยังไงที่ต้องรู้
primitive const message: string = "Hello World";

กฎง่าย ๆ ที่ใช้ได้ตั้งแต่วันนี้
· เป็น object ธรรมดา → ใช้อะไรก็ได้ แต่ให้ทั้งทีมใช้อันเดียวกัน
· ไม่ใช่ object (union · tuple · ชื่อเล่นของ string) → ต้องใช้ type ไม่มีทางเลือก
· กำลังจะต่อเติม type ของ library → ต้องใช้ interface ไม่มีทางเลือกเหมือนกัน
· นอกจากนั้น อย่าเสียเวลาเถียงกัน — ความต่างที่เหลือแทบไม่กระทบงานประจำวัน

5 · as (type assertion) — ทำอะไรได้ ทำอะไรไม่ได้

as ทำอะไรas ไม่ทำอะไร
สั่ง compiler ว่า “ค่านี้เป็น type นี้ ไม่ต้องตรวจ” ไม่แปลงค่า — ไม่มีการ convert เกิดขึ้นเลยแม้แต่นิดเดียว
assert ไป type ที่กว้างกว่าหรือแคบกว่าของเดิม ไม่สร้างช่องใหม่ — ช่องที่ขาดยังขาดอยู่ตอนรัน
หายไปตอนคอมไพล์ เหมือนไม่เคยมี ไม่เช็คตอนรัน — ไม่มี code ตรวจอะไรถูกใส่เข้าไปใน .js เลย
