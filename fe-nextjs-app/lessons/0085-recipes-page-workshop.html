🍣 เทียบกับของจริง

การ์ด 12 ใบที่ชื่อ recipe 1 … recipe 12 คืออาหารพลาสติกในตู้โชว์หน้าร้านญี่ปุ่น
ร้านยังไม่ต้องทำซูชิจริงสักคำ ก็จัดตู้ได้แล้วว่าจานวางตรงไหน ตู้กี่ชั้น ป้ายราคาอ่านชัดไหม · พอเมนูจริงพร้อม ค่อยสลับของจริงเข้าไปในตำแหน่งเดิม — นี่คือหน้า 48 → หน้า 50 พอดี

ที่ไม่เหมือนกัน: อาหารพลาสติกไม่มีใครเผลอกิน แต่ข้อมูลปลอมในโค้ดหลุดขึ้น production ได้จริงและไม่มีอะไรฟ้อง — ข้อความ 8 recipes · page 1 of 7 ก็คือของปลอมชิ้นหนึ่งที่ติดมาถึงหน้า 50 แล้ว (ดูหัวข้อถัดไป)
และอาหารพลาสติกหน้าตาเหมือนของจริง แต่ mock data มัก “สวยเกินจริง” — ชื่อสั้นทุกใบ มีรูปทุกใบ · ของจริงจะมีชื่อยาวสามบรรทัดกับเมนูที่ไม่มีรูป ซึ่ง mock ไม่เคยทดสอบให้

สามอย่างในหน้า 48 ที่ติดมาถึงหน้า 50

⚠️ 1 · ข้อความ “8 recipes · page 1 of 7” เป็นข้อความ mock ไม่ใช่ตัวเลขจริง

หน้า 48 วาดการ์ด 12 ใบ แต่ข้อความบนหัวบอก 8 recipes · และทั้งโปรเจกต์ยังไม่มีระบบแบ่งหน้าเลย แต่บอกว่า page 1 of 7
ที่มาของมันเห็นได้ชัดในสไลด์หน้า 42 — นี่คือข้อความจากภาพออกแบบที่ Claude Design สร้างให้ ซึ่งถูกพิมพ์ตามลงโค้ดตรง ๆ · หน้า 49 ที่ refactor แล้วก็ยังพิมพ์ข้อความนี้ไว้เหมือนเดิม และหน้า 50 ก็ยังโชว์ข้อความนี้อยู่
ไม่ผิดสำหรับขั้น mock · แต่ต้องรู้ว่ามันคือของปลอม · ตัวเลขนี้ควรคำนวณจากข้อมูล เช่น `${state.recipes.length} recipes found` (เฉลยภารกิจท้ายบททำให้ดู) ส่วน “page 1 of 7” ต้องรอจนมีการแบ่งหน้าจริงจาก API

⚠️ 2 · grid-cols-4 คือ 4 คอลัมน์ทุกขนาดจอ

ไม่มี prefix อะไรนำหน้า = ใช้กับทุกความกว้าง · คิดเลขง่าย ๆ บนมือถือกว้าง 375px: หักขอบซ้ายขวาของ Container ตัวแทนที่ผมเขียน (px-4 = 16px × 2) กับช่องไฟ gap-4 สามช่อง (16px × 3) เหลือ 295px แบ่ง 4 ใบ = ใบละไม่ถึง 74px (ความกว้างราวนิ้วโป้งหนึ่งนิ้ว)
ทั้งที่ prompt ออกแบบในสไลด์หน้า 23 ขอไว้เองว่า “Grid of RecipeCard (4 columns desktop, 2 columns tablet, 1 column mobile)” · แก้เป็น grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 — รายละเอียดอยู่หัวข้อ responsive ข้างล่าง

⚠️ 3 · key ทำจาก index

key={`recipe-${index}`} ในหน้า 48 ไม่ทำให้เกิด warning เพราะ key ไม่ซ้ำกันจริง · และในหน้านี้ยังไม่เป็นบั๊กเพราะรายการไม่เคยเปลี่ยนลำดับ
หน้า 49 แก้เป็น key={recipe.id} ถูกต้องแล้ว — หัวข้อ key ข้างล่างจะพิสูจน์ว่าทำไมต้องเปลี่ยน

จังหวะที่ 2 — แยกรายการออกเป็น container (สไลด์หน้า 49)

สไลด์หน้า 49 เขียนเหตุผลไว้หนึ่งบรรทัด: “Split recipe list into container to handle business of recipe list”

"use client" ใน RecipeList — จำเป็นไหม

RecipeList หน้า 49 ไม่มี useState · ไม่มี useEffect · ไม่มี onClick · มีแค่ .map() ข้อมูลที่ import มา
ใน บท 78 เราเห็นแล้วว่า ลืม "use client" ในไฟล์ที่มี hook → build พัง · คำถามกลับด้าน: ใส่ในไฟล์ที่ไม่มี hook เลย จะเกิดอะไร
อย่าเดา · ผม build ทั้งสองแบบ (ลบ .next ทิ้งก่อนทุกครั้ง) แล้ววัดของที่ต่างกันจริง 

// แบบ A — ตามสไลด์หน้า 49
"use client";
import RecipeCard from "@/components/RecipeCard";
import { RECIPES_MOCK_DATA } from "./recipes";

// แบบ B — ลบสองบรรทัดแรกทิ้ง ที่เหลือเหมือนเดิมทุกตัวอักษร
import RecipeCard from "@/components/RecipeCard";

client boundary

// containers/RecipeList/RecipeList.tsx
import Link from "next/link";
import RecipeCard from "@/components/RecipeCard";
import { Skeleton } from "@/components/ui/skeleton";
import type { Recipe } from "./recipes";

export type RecipeListState =
  | { status: "loading" }
  | { status: "error"; message: string }
  | { status: "success"; recipes: Recipe[] };

const RecipeList = ({ state }: { state: RecipeListState }) => {
  if (state.status === "loading") {
    return (
      <>
        {Array.from({ length: 8 }).map((_, index) => (
          <Skeleton key={`skeleton-${index}`} className="aspect-[4/3] w-full" />
        ))}
      </>
    );
  }

  if (state.status === "error") {
    return (
      <div role="alert" className="col-span-full py-16 text-center">
        <p className="font-medium">Something went wrong</p>
        <p className="text-muted-foreground">{state.message}</p>
      </div>
    );
  }

  if (state.recipes.length === 0) {
    return (
      <div className="col-span-full py-16 text-center">
        <p className="font-medium">No recipes match your search</p>
        <Link href="/recipes" className="text-primary underline">
          Clear filters
        </Link>
      </div>
    );
  }

  return (
    <>
      {state.recipes.map((recipe) => (
        <RecipeCard
          key={recipe.id}
          name={recipe.name}
          level={recipe.level}
          imageUrl={recipe.imageUrl}
          owner={recipe.owner}
        />
      ))}
    </>
  );
};

export default RecipeList;
// containers/RecipeList/index.ts
export { default } from "./RecipeList";
export type { RecipeListState } from "./RecipeList";
// app/recipes/page.tsx
import { Container } from "@/components/Bases";
import RecipeList, { type RecipeListState } from "@/containers/RecipeList";
import { RECIPES_MOCK_DATA } from "@/containers/RecipeList/recipes";

const subtitle = (state: RecipeListState) => {
  if (state.status === "loading") return "Loading recipes…";
  if (state.status === "error") return "Could not load recipes";
  return `${state.recipes.length} recipes found`;
};

const RecipesPage = () => {
  const state: RecipeListState = { status: "success", recipes: RECIPES_MOCK_DATA };

  return (
    <div className="pt-10 pb-8">
      <Container>
        <p className="wongnok-text-h2">All Recipes</p>
        <p className="wongnok-text-body text-muted-foreground mt-2">{subtitle(state)}</p>
        <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4 mt-7">
          <RecipeList state={state} />
        </div>
      </Container>
    </div>
  );
};

export default RecipesPage;
